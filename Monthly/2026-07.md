1. **[07/05] AI API 集成成功：** 将外部 LLM 的文本摘要和情感分析能力，通过 Python 后端稳定接入到主产品流程中，实现了核心业务逻辑的智能化升级。

## 📉 本月卡点/不足（需要解决的 3 个问题）

1. **技术栈切换成本过高：** 在 AI、Vue 前端重构和嵌入式固件开发之间频繁切换，导致心流中断，尤其在 O4 和 O5 的交界处效率明显下降。
2. **副业获客渠道单一化风险：** 仅依赖了个人人脉进行付费验证，缺乏系统化的市场推广或引流机制，变现的规模化能力存疑。
3. **嵌入式硬件调试时间预估不足：** PTL 的通信协议和外部环境因素（如网络抖动）导致固件调试周期比预期长 1.5 倍，占用了本月大量精力，影响了 O1 的收尾工作。
